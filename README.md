# Machine Learning project - Action Recognition & Temporal Action Segmentation
## Abstract
This report presents the details about the approaches used to solve two machine learning problems: Action Recognition and Temporal Action Segmentation. For Action Recognition, a stacked ensemble of bidirectional Gated Recurrent Units (BiGRU), Random Forests, and Histogram-based Gradient Boosting Classifiers (BiGRU + RF + HGB) is implemented.
For Temporal Action Segmentation, a deep sequence-to-sequence BiGRU trained on raw and differential features is used, combined with a temporal post-processing filter to address oversegmentation.
